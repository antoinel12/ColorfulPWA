🆘 Dépannage

L'extension ne fonctionne pas?

1. Assurez-vous d'avoir chargé le dossier extension/ dans chrome://extensions/
2. Vérifiez que le "Mode de développeur" est activé
3. Ouvrez la console (F12) pour voir les erreurs
4. Rechargez l'extension avec l'icône rafraîchir
